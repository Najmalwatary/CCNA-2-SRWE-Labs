# CCNA 2 – SRWE Labs

A collection of hands-on networking labs and practical implementations completed during my CCNA 2 (Switching, Routing, and Wireless Essentials) learning journey using Cisco Packet Tracer.

## About This Repository

This repository documents my practical networking exercises, configurations, and experiments as I develop my networking skills and strengthen my understanding of Cisco networking technologies.

Each lab includes its network topology, implementation details, configuration commands, and verification results.

## Learning Objectives

- Understand and configure VLANs and trunking.
- Implement Inter-VLAN Routing.
- Configure DHCP and DHCPv6 services.
- Work with IPv6 addressing and SLAAC.
- Configure network access using SSH and Telnet.
- Implement EtherChannel.
- Develop practical troubleshooting skills.

## Tools & Technologies

- Cisco Packet Tracer
- Cisco IOS CLI
- IPv4 and IPv6
- Switching and Routing Protocols

## Repository Structure

Each lab is organized in its own directory containing relevant project files, topology diagrams, documentation, and configuration commands.
